Análise em MySQL utilizando [dados](https://www.kaggle.com/datasets/alijalali4ai/scimago-universities-and-institutions-ranking) sobre a colocação das universidades e instiuições de ensino em 2025, de modo a responder os seguintes questionamentos:

 * Quantas Universidades e Instituições participaram por país?
 * Quantos % cada setor compõe em relação ao total?
 * Qual foi a universidade brasileira melhor colocada no Ranking? E a pior?

 Ademais, de modo a automatizar o processo, foi utilizada a bibliotecas do Python `mysql.connector` e `pandas`, inserindo as informações do arquivo .csv no banco de dados.
